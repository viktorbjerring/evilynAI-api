EvilynAI API (1.0.0)

Download OpenAPI specification:

REST API for the EvilynAI backend. All endpoints except /health and /login require a Bearer JWT token obtained from POST /api/login.

The SSE stream endpoint (GET /api/stream) also accepts the token as a ?token= query parameter, because EventSource cannot set custom headers.

chat

Send a message and receive an AI response

Accepts either JSON (text) or multipart/form-data (audio).

Text input: send Content-Type: application/json with a message field.

Audio input: send Content-Type: multipart/form-data with an audio file. The file is transcribed server-side via OpenAI Whisper. The transcription is returned in input_transcription.

The response may include audio_url — a TTS response ID. Fetch the audio from GET /api/tts/fetch/{audio_url}.

bearerAuth

Each SSE event has the form:

OAuth redirect callback

Handles the redirect from Google after the user approves (or denies) access. Not called directly — Google redirects here after the consent screen.

On success:

  • Exchanges the authorization code for credentials
  • Writes the token to disk
  • Reloads the toolset so the tool picks up the new token
  • Returns an HTML success page

On denial:

  • Returns an HTML page indicating the authorization was denied

On state mismatch (CSRF):

  • Returns 400
